# Logos oficiais — Fold Videos

Todas com **fundo transparente**. Use estas, não as da pasta de cima (que são rascunhos do processo de decisão).

## Ícone (a pasta sozinha)
- `fold-logo.svg` — vetor, escala infinita. **Use esta sempre que puder.**
- `fold-icone-16/32/48/64/128/180/256/512/1024.png` — tamanhos prontos
- `favicon.ico` — ícone de aba do navegador (multi-tamanho)

Quando usar cada PNG:
- **16, 32, 48** → favicon, ícones pequenos
- **180** → ícone de app no iPhone (apple-touch-icon)
- **256, 512** → redes sociais, posts
- **1024** → ícone de app (App Store / Play Store), impressão

## Wordmark (ícone + texto "Fold")
- `fold-wordmark-claro.svg` / `-512.png` / `-1024.png` → texto CLARO, para fundo escuro
- `fold-wordmark-escuro.svg` / `-512.png` / `-1024.png` → texto ESCURO, para fundo claro

## Monocromática (uma cor só — para carimbo, marca d'água, fundo colorido)
- `fold-mono-creme.svg` / `-256.png` / `-512.png` → para fundos escuros
- `fold-mono-escuro.svg` / `-256.png` / `-512.png` → para fundos claros
